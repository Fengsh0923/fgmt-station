> **5 篇 GetNote 已在凌晨 03:30 完成深度解读**，原文留档。核心观点摘要：

1. **《AI Agent 行业发展讨论：从 Open Sora 到 Hermes Agent》** — Agent 框架格局正从"中心化框架（LangChain/AutoGen）"分裂为"Harness 派（Hermes/OpenClaw）"和"垂直 SaaS 派"，核心分歧在"是否暴露 OS 原语"。

2. **《AI 教练三次迭代历程与搭建分享》** — 教练类 Agent 的可复用范式：1.0 prompt 工程 → 2.0 Memory + 长上下文 → 3.0 多 Agent 协作 + 工具链。F哥 AI Coach 项目正处 2.5 阶段。

3. **《十六进制觉醒访谈：火山引擎 Data Agent 产品解读》** — 火山引擎押注"数据 Agent"赛道，对标 Snowflake Cortex，下游应用：自助 BI、数据治理、SQL 生成。**对 SYGJ Dashboard 路线是直接参照**。

4. **《开源 Hermes AI Agent 与 Harness Engineering 方法论》** — Harness 派的方法论确立：操作系统层 ≠ 应用层，Agent Harness 提供"原语集合 + 编排时序"，让上层 skill 自由组合——这是飞虾队架构理论基础。

5. **《播客访谈：解析 Agent Harness 与 AI Agent 开发工具链》** — 工具链分三层：模型 API（Anthropic/OpenAI/月之暗面）→ Harness（Claude Code/OpenClaw/Hermes）→ Skill 生态（用户产出）。F哥 飞虾队已三层全覆盖。
